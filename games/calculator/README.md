# Calculator ∞ Alchemia 解密终端

一款 MVVM 架构的 tkinter 计算器，内置 Alchemia 解密谜题与成就系统。

## 语言 / 类型
- Python / tkinter 图形界面计算器（MVVM 架构）

## 目录要点
- `main.py` —— 装配入口（Bootstrap）
- `model.py` / `viewmodel.py` / `view.py` —— MVVM 三层
- `calculator.py`、`alchemia.py`、`utils.py` —— 计算与解密逻辑
- `test_model.py` —— 模型单元测试；`ENHANCEMENT.md` —— 功能说明

## 运行方式与依赖
- 运行：`F:\Python314\python.exe main.py`
- 依赖：无（仅标准库 tkinter）
