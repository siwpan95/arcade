# KID-A WALKER 游戏性增强 PRD

## 项目信息

- **Language**: 中文
- **Programming Language**: Python + pygame-ce + numpy
- **Project Name**: kid_a_walker
- **原始需求**: KID-A WALKER 是一款伪3D步行模拟器，当前缺少目标、危险、奖励、进度、交互和策略，体验单调。需要在保持"探索"核心体验的前提下，增加互相关联的游戏性系统。

---

## 产品定义

### 产品目标

**将"漫无目的的行走"转化为"有目标的探索"——在赛博废墟中生存、收集、选择，让每次行走都有意义。**

### 用户故事

1. **As a 探索者**, I want 在探索中发现可收集的"数据碎片"并看到进度增长, so that 我的行走有明确目标和回报感
2. **As a 生存者**, I want 在红色警示区和暗室中面临环境威胁（能量衰减/辐射伤害）, so that 我需要做出路线选择而非漫无目的游走
3. **As a 数据拾荒者**, I want 与装饰物互动获取不同类型的资源, so that 不同区域有不同的探索价值，我会有动力去不同类型的区域
4. **As a 探险家**, I want 在大地图上看到已探索区域和未探索区域的区分, so that 我能追踪自己的探索进度并获得发现感
5. **As a 赛博行者**, I want 用收集的资源激活/增强自身能力（如视野扩展、移速提升）, so that 我能做出策略性选择来优化后续探索

## 需求池

### P0 — 核心体验（必须有）

| # | 需求 | 描述 | 关联系统 |
|---|------|------|----------|
| P0-1 | **能量系统** | 玩家拥有能量条（100→0），移动缓慢消耗能量；红色警示区(3)加速消耗；青绿发光柱(2)附近可缓慢恢复；能量归零游戏结束 | 生存→交互→奖励 |
| P0-2 | **数据碎片收集** | 每个装饰物类型对应一种数据碎片（10种）；靠近装饰物按E互动可拾取碎片；碎片计分显示在HUD | 奖励→进度→探索 |
| P0-3 | **区域威胁** | 红色警示区(3)：能量消耗×3；暗室类型房间：视野距离缩短为正常的60%；酸液池(5区域)：接触绿色格子造成能量骤降 | 危险→策略→生存 |
| P0-4 | **HUD增强** | 新增：能量条（左上角）、已收集碎片类型计数（右上角）、当前区域危险等级提示 | 进度→反馈 |
| P0-5 | **死亡/重启** | 能量归零后显示结算画面（收集碎片统计、存活时间、探索区块数），按R重启 | 循环→进度 |

### P1 — 深度体验（应该有）

| # | 需求 | 描述 | 关联系统 |
|---|------|------|----------|
| P1-1 | **碎片图鉴** | Tab大地图新增图鉴页（按Q切换地图/图鉴），显示10种碎片收集进度，未收集的显示为剪影，已收集的显示全彩图标+区域描述 | 进度→收集→探索 |
| P1-2 | **环境互动** | 青绿发光柱(2)：靠近按E回复能量20；金色宝库(4)：靠近按E获得高分碎片；紫色能量核心(6)：靠近按E获得临时能量护盾（10秒减半消耗）；橙色光源(7)：靠近按E恢复少量能量+标记位置 | 交互→策略→奖励 |
| P1-3 | **能力增强** | 收集特定组合碎片可解锁被动能力：5个青绿碎片→视野+15%；5个紫色碎片→能量消耗-20%；5个橙色碎片→移速+15%；10种各1个→危险区域免疫5秒（冷却60秒） | 奖励→策略→进度 |
| P1-4 | **区块探索追踪** | 离开区块时记录已探索标记（存入字典，不随区块清理删除）；大地图上已探索区块显示绿色边框，未探索的暗色；HUD显示总探索区块数 | 进度→探索→地图 |
| P1-5 | **结算评分** | 结算画面计算综合评分：碎片×100 + 区块数×50 + 存活时间（秒）×2 + 全类型收集奖励×500 | 进度→目标 |

### P2 — 锦上添花（可以有）

| # | 需求 | 描述 | 关联系统 |
|---|------|------|----------|
| P2-1 | **危险预警** | 靠近红色警示区时HUD闪烁红色边框+低频蜂鸣音效 | 危险→氛围 |
| P2-2 | **收集音效** | 互动拾取时播放短促的合成音效（根据碎片类型变调） | 奖励→反馈 |
| P2-3 | **漂浮拾取物** | 装饰物周围偶尔生成可见的漂浮碎片（3D精灵），引导玩家靠近 | 探索→视觉 |
| P2-4 | **最高分记录** | 本地存储历史最高分，结算画面对比当前与最高 | 进度→重玩 |
| P2-5 | **稀有事件** | 低概率出现特殊发光门，互动后传送到远距离区域（强制冒险） | 探索→惊喜 |

```
│ [■■■■■■■□□□] 78%          ENERGY         ◆3  ★2  ●1  ...    │
│ ← 能量条（渐变：青绿→红色）                    ← 碎片计数缩写    │
│                                                              │
│                                                              │
│                                                              │
│                        [准星]                                 │
│                                                              │
│                                                              │
│                                                              │
│           ⚠ DANGER ZONE                    [E] INTERACT       │
│           ← 区域危险提示                      ← 交互提示       │
├──────────────────────────────────────────────────────────────┤
│ POS [10.5,10.5]  SECTOR (0,0) │ KID-A WALKER // 03:42 │ ... │
│                    ZONE: RED ALERT ⚠                     │

```

- **能量条**：屏幕左上角水平条，宽200px高12px，颜色从青绿(#00FFC8)渐变到红色(#FF3344)随能量降低变化
- **碎片计数**：右上角，每种碎片用其主题色的圆点+数字显示
- **区域危险提示**：屏幕中央偏下，进入危险区时红色闪烁文字"DANGER ZONE"
- **交互提示**：靠近可互动装饰物时，中央下方显示"[E] INTERACT"，带装饰物主题色
- **HUD底栏**：在现有基础上增加 E 交互键提示

## 待确认问题

1. **能量衰减速率**：每秒消耗多少能量？建议初始值 1点/秒（100秒自然耗尽），红色区域3点/秒。是否需要难度选择？
2. **装饰物互动冷却**：同一个装饰物是否可以反复互动？建议：同一区块的同一装饰物只能互动一次，记录在独立字典中（不随区块清理）。
3. **区块探索定义**：什么算"已探索"？建议：玩家进入区块后停留超过3秒，或进入区块中心10格范围内。
4. **能力增强的持久性**：解锁的能力是否在死亡后保留？建议：不保留（Roguelike风格），但碎片图鉴进度跨局保留。
5. **地图持久化策略**：当前区块离开后会清理重建（每次布局不同），这是否与"探索追踪"矛盾？建议：保持现有逻辑，探索追踪仅记录"玩家到过该坐标的区块"，不影响区块生成。
6. **暗室视野缩减**：实现方式是在暗室类型房间渲染时减小 MAX_DEPTH，还是通过增加雾化浓度？需确认性能影响。
7. **结算后是否保存**：是否需要将最高分持久化到本地文件？建议简单 JSON 即可。

## 技术备注

- 现有装饰物类型(2-11)天然映射为10种碎片类型，无需新增地图符号
- 区块探索记录需在 `WorldMap` 外维护独立字典（因区块会被清理）
- 能量系统需在 `Game` 类中新增 `energy` 属性及消耗/恢复逻辑
- 交互系统需在事件循环中监听 E 键，并检测玩家前方装饰物距离
- HUD增强需修改 `draw_hud()` 函数，增加能量条和碎片计数渲染
- 粒子系统已支持按装饰物类型着色，碎片拾取动画可复用
