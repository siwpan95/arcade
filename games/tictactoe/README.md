# Tic-Tac-Toe

异形井字棋增强版（命令行）。

## 简介
命令行井字棋：多种棋盘形状（可扩展）、多种干扰项类型（基础/星型/随机/延迟）、特殊棋子（炸弹/冻结/转换/护盾）、双人对战，带彩色终端输出。

## 语言 / 类型
- 语言：Python（仅标准库，无第三方依赖）
- 类型：命令行游戏（CLI）

## 目录要点
- `井字棋8.py`：单文件程序（全部逻辑）
- `井字棋8.spec`：PyInstaller 打包配置

## 运行方式与依赖
```
python 井字棋8.py
```
- 依赖：Python 标准库。
- 提示：程序输出含 emoji 等特殊字符，默认 GBK 控制台会报 `UnicodeEncodeError`；请先 `chcp 65001` 或设置 `PYTHONUTF8=1` 再运行。

## 测试状态
- `py_compile` 语法检查：通过（1 个 .py）。
- 运行：CLI 可正常启动并进入对局（UTF-8 下退出码 0）；默认 GBK 控制台下因 emoji 输出报编码错误。
