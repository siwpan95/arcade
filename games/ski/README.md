# ASCII 滑雪游戏 · SkiFree 增强版

> 基于 1991 年 Microsoft 经典 SkiFree 机制重构的 Python + Tkinter ASCII 滑雪游戏。
> 在保留原版「滑雪 → 躲树 → 收旗 → 被雪人吃」核心乐趣的同时，加入跳跃、加速、
> 暂停、多模式、高分持久化等现代化特性，并对 Tkinter Text 渲染做了性能优化。

---

## ✨ 特性一览

| 类别 | 原版 | 本增强版 |
|------|------|----------|
| 障碍物 | 树、岩石、雪橇犬等 | 树 ♣ / 岩石 ● / 旗子 ¶ / 跳台 ♦ |
| 雪人 Yeti | 2000m 后追击 | 200m 触发，加速可拉开距离 |
| 跳跃 | 彩虹跳台 | ♦ 跳台，可越过树/岩石 +5 风格分 |
| 加速 | F 键 Fast Mode | F 键 3 秒 ×2 速度 + 6 秒冷却 |
| 暂停 | — | P 暂停 / T 单帧步进 |
| 模式 | 单一无尽 | 无尽 / 回转 / 自由式 |
| 难度 | 固定 | 每 50m 提升，最高 Lv8 |
| 高分 | — | JSON 持久化，按模式分别记录 |
| HUD | 仅分数 | 分数/距离/风格/速度/加速槽/雪人警告 |
| 渲染 | — | 内存网格整帧写入，告别逐字符卡顿 |

## 🎮 控制

```
← / →   或  A / D    转弯（轻 / 重两档）
F                    加速冲刺（3 秒，冷却 6 秒）
P                    暂停 / 继续
T                    暂停时单帧步进（调试利器）
R                    重新开始当前模式
1 / 2 / 3            主菜单切换模式：无尽 / 回转 / 自由式
空格 / 回车           开始游戏
ESC                  返回主菜单
```

## 🕹️ 游戏模式

### 1. 无尽模式（Endless）
原版体验：滑雪、躲树、收旗。滑到 **200m** 时，**雪人 ☃** 从屏幕底部追出。
- 雪人速度恒定，比正常滚动略快
- 按 **F 加速**可拉开距离（加速期间雪人几乎停滞）
- 加速有冷却，要留到关键时刻
- 被雪人追上 → 直接被吃掉，游戏结束

### 2. 回转模式（Slalom）
聚焦旗门：尽可能多地收集旗子 ¶，限时计分。无雪人，专注走线。

### 3. 自由式（Freestyle）
跳跃做特技：踩 ♦ 跳台起跳，空中越过障碍物。每次成功跳跃 **+5 风格分**，
旗子也算风格分。风格分至上。

## 🏗️ 架构

```
G:\ice\
├── main.py        # 编排层：键盘事件 → 引擎 tick → UI 渲染
├── engine.py      # 纯游戏逻辑（零 UI 依赖），含雪人/跳跃/加速/碰撞
├── ui.py          # Tkinter 渲染层：内存网格 + 整帧写入 + HUD
├── config.py      # 集中配置：尺寸/字符/颜色/参数/模式
├── storage.py     # 高分 JSON 持久化（按 mode 分别记录，原子写入）
├── forc.py        # [遗留] 早期单文件版，仅作参考，不维护
└── highscores.json # 运行后自动生成
```

### 设计原则
- **逻辑 / 渲染分离**：`engine.py` 零 tkinter 依赖，可单测
- **配置集中**：所有可调参数在 `config.py`，平衡性调参不动业务代码
- **事件流**：`tick()` 返回事件列表，UI 据此播特效，解耦干净
- **原子写入**：高分文件用 `tempfile + os.replace` 写入，防中途崩溃损坏

## ⚡ 性能优化说明

原版 `ui.py` 每帧对 80×30 = 2400 个单元逐个 `mark_set + insert`，实测在 Tkinter Text
下会触发大量重绘与几何树重建，n=200 时单帧可从 3ms 飙到 47ms。

本版优化：
1. **构建内存二维网格** → 整帧一次 `insert`，仅对彩色单元 `tag_add`
2. **背景道路稀疏化**：每 4 格放一个点，减少字符数
3. **逻辑/渲染解耦**：`tick` 与 `render` 分离，暂停时只 tick 不 render
4. **滚动节奏**：障碍物每 2 帧滚一次（可调），保持流畅但降速
